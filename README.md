# Weather Database — Task 3
## Про проєкт
Цей етап проєкту додає нову логіку: обчислення колонки is_safe_to_go_out, яка визначає, чи безпечно виходити на вулицю.

## Виконано в рамках завдання 3
Додано колонку is_safe_to_go_out до таблиці astronomy_info.

Колонка автоматично заповнюється під час імпорту, на основі сили вітру та освітлення місяця:

якщо wind_kph > 20 або moon_illumination < 10, то значення no;

інакше — yes.

Реалізовано обчислення через Enum SafetyLevelLower.

## Структура
app/models.py — оновлені моделі

app/main.py — логіка заповнення колонки при імпорті

alembic/versions/... — міграція для додавання нової колонки
