# Weather Database CLI — Task 4
## Про проєкт
Цей етап реалізує консольну утиліту для зручного перегляду та фільтрації даних із бази.

## Виконано в рамках завдання 4
Додано CLI-інтерфейс для:

перегляду записів погоди;

фільтрації за країною або датою;

відображення безпечних/небезпечних днів.

Команди реалізовані з використанням модуля argparse.

## Структура
cli_tool.py — основна CLI утиліта

app/db.py, app/models.py — імпортуються для роботи з базою

## Навігація по завданнях
- **Завдання 1** – опис моделей (ORM) — task-1-models
- **Завдання 2** – рефакторинг структури БД через Alembic — task-2-alembic-refactor
- **Завдання 3** – обчислення колонки is_safe_to_go_out — task-3-safety-logic
- **Завдання 4** – консольна утиліта (CLI) — task-4-cli-tool
- **Завдання 5** – міграція з PostgreSQL до MySQL — task-5-mysql-migration
